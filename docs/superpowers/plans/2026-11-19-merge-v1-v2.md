**Goal:** Merge `versi2/portofolio-master` (`v2`) onto the root portfolio (`v1`, `master`) while preserving all 2026-11-18 `v1` updates, unifying project data into `src/data/projects.ts`, rendering informative bilingual 3D card nodes + fixed focus/modal details, and adding a bilingual screenshot showcase to `ProjectLayout.astro`.

**Architecture:** Use `v2` as the base Astro 7 + `@astrojs/node` standalone app at root, driven by a new `src/data/projects.ts` single source of truth shared across `Projects.astro`, `content.ts`, `panels.ts`, `controls.ts`, `article.ts`, and `portfolioContext.ts`. Extract pure canvas-card layout and camera-target helpers (`card-layout.ts`, `camera-math.ts`) so core logic is TDD-tested with Node 25 (`node --test`), while `npx astro check`, `npm run build`, and Chrome DevTools live browser inspection verify the full UI across `320px–1440px`.

**Tech Stack:** Astro `^7.3.2`, `@astrojs/node` `^11.1.8`, `@astrojs/sitemap` `^3.7.4`, TypeScript `^6.0.3`, Three.js `^0.186.0`, Fuse.js `^7.5.0`, NanoID `^6.0.2`, OpenAI SDK `^7.33.0`, Node `v25.1.0` (`node --test`).

**Spec:** `docs/superpowers/specs/2026-11-19-merge-v1-v2-design.md`

- Single source of truth `src/data/projects.ts` separates honest placeholder `desc` (`ID`/`EN`) from `aiSummary` for the 5 pending projects (`1A`).
- 3D Gallery nodes (`panels.ts`) render cards only (no screenshots on 3D nodes); screenshots live on `/projects/<slug>` pages via `ProjectLayout.astro`.
- `@astrojs/node` standalone adapter + `astro:env` schema retained; `.env` stays gitignored and never committed; `site: 'https://mahdihabibi.example'` stays marked `TODO(deploy)`.
